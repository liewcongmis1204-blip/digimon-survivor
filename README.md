# 数码兽生存战记 · Digimon Survivor

一个浏览器运行的生存战斗游戏原型。使用原生 HTML、CSS 和 JavaScript，无需安装依赖。

## 运行方法

- 下载仓库中的 `index.html`，用 Chrome、Edge 或其他现代浏览器打开；或
- 在 GitHub 仓库 Settings → Pages 中，将部署来源设为 `Deploy from a branch`，分支选择 `main`、目录选择 `/ (root)`，保存后等待 GitHub Pages 发布。

## 当前玩法

- 选择亚古兽或加布兽作为搭档
- 使用 WASD / 方向键移动，自动瞄准攻击
- 击败敌人并收集数据晶体升级
- 升级时选择攻击、移动速度、连射、生命、射程或经验强化
- 达到 5 级触发简化进化效果
- 生存 55 秒后出现 Boss

## 说明

这是学习用途的粉丝游戏原型，角色采用简化代码绘图，未包含官方游戏素材。该项目不是官方数码宝贝游戏。
